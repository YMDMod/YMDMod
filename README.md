### Возможности

- Страница управления модом в клиенте — пункт «YMDMod» в боковом меню
- Каталог аддонов: установка и обновление в одно действие без перезапуска клиента
- Поддержка настроек аддонов, зависимостей между ними и общего API
- Уведомление о выходе новых версий мода и обновление по кнопке
- Команда `ymdmod` для установки, восстановления и удаления мода
- Полное удаление с возвратом клиента в исходное состояние

### Установка

Требуется установленная [Яндекс Музыка](https://music.yandex.ru/download) для Windows. Откройте PowerShell
(права администратора не требуются) и выполните команду:

```powershell
iwr https://raw.githubusercontent.com/YMDMod/YMDMod/main/install.ps1 | iex
```

Установщик закроет клиент, встроит мод и запустит клиент снова. После этого в боковом меню появится пункт
«YMDMod» — страница управления модом.

Одновременно устанавливается команда `ymdmod`. Если в текущем окне PowerShell она недоступна, откройте новое окно.

### Команда ymdmod

Команда `ymdmod` без параметров открывает меню. В нём отображаются расположение и версия клиента, а также
состояние мода; доступны действия «Установить», «Починить», «Обновить мод» и «Удалить». Выбор — стрелками
и Enter, выход — Esc.

Те же действия без меню:

```powershell
ymdmod install     # установить мод или обновить его до последней версии
ymdmod repair      # заново встроить мод, например после обновления Яндекс Музыки
ymdmod uninstall   # вернуть клиент в исходное состояние
ymdmod status      # показать текущее состояние
```

Если клиент запущен, `ymdmod` закроет его перед выполнением действия и запустит после.

### Обновления

**Яндекс Музыка.** При обновлении клиент переустанавливается, и мод из него удаляется. Работоспособность
клиента при этом не нарушается. Чтобы вернуть мод вместе с аддонами и настройками, выполните `ymdmod`
и выберите «Починить».

**Мод.** Мод самостоятельно проверяет наличие новой версии и сообщает о ней в клиенте. Кнопка «Обновить»
закрывает клиент, обновляет мод и запускает клиент снова. Та же кнопка доступна в верхней части вкладки
«Каталог»; кроме того, обновить мод можно командой `ymdmod install`. Архив новой версии проверяется по
контрольной сумме из релиза на GitHub; при несовпадении установленная версия остаётся без изменений.

### Удаление

Выполните `ymdmod` и выберите «Удалить». Клиент будет возвращён в исходное состояние, после чего мод
предложит удалить свои файлы и команду `ymdmod`. Настройки мода хранятся в `%APPDATA%\YandexMusic\YMDMod`
и при необходимости удаляются вручную.

### Важная информация

- Для встраивания мода изменяются файлы клиента (`app.asar` и `Яндекс Музыка.exe`), поэтому цифровая подпись
  исполняемого файла перестаёт быть действительной. После удаления мода восстанавливаются исходные файлы,
  и подпись снова действительна.
- Мод не затрагивает учётную запись, подписку и загрузку треков и не обходит механизмы защиты.
- Аддоны выполняются внутри клиента. Каталог содержит только проверенные аддоны; устанавливать аддоны
  «из папки» рекомендуется только при доверии к их автору.

<details>
<summary><b>Устранение неполадок</b></summary>

<br>

В первую очередь выполните `ymdmod` → «Починить». Если проблема сохраняется, подготовьте:

- журнал мода: `%APPDATA%\YandexMusic\YMDMod\ymdmod.log`;
- сведения о клиенте, собранные модом: `%APPDATA%\YandexMusic\YMDMod\support.json`;
- журнал загрузчика, если мод не запускается: `%TEMP%\ymdmod-loader.log`;
- вывод команды `ymdmod status`.

Приложите эти данные к [issue](https://github.com/YMDMod/YMDMod/issues) — это существенно ускорит
диагностику.

</details>

### Разработка

```powershell
npm test
```

Релиз создаётся тегом `vX.Y.Z`, совпадающим с версией в `package.json`. Архив `ymdmod-X.Y.Z.zip`
и его контрольную сумму GitHub Actions собирает и прикладывает к релизу автоматически.
