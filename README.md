### Возможности

- Страница мода прямо в клиенте: пункт «YMDMod» в меню слева
- Каталог аддонов — установка и обновление в один клик, без перезапуска клиента
- Аддоны с настройками, зависимостями и общим API друг для друга
- Мод сам сообщает о новых версиях и обновляется по кнопке
- Команда `ymdmod`, чтобы поставить, починить или удалить мод
- Удаляется начисто: клиент возвращается в исходное состояние

### Установка

Нужна [Яндекс Музыка](https://music.yandex.ru/download) для Windows. Откройте PowerShell (обычный, без прав
администратора) и выполните:

```powershell
iwr https://raw.githubusercontent.com/YMDMod/YMDMod/main/install.ps1 | iex
```

Установщик сам закроет клиент, встроит мод и откроет клиент обратно. В меню слева появится пункт «YMDMod» —
это и есть страница мода.

Заодно появится команда `ymdmod`. Если в этом окне PowerShell она не находится, откройте новое окно.

### Команда ymdmod

Просто `ymdmod` открывает меню: там видно, где стоит клиент, какой версии, стоит ли в нём мод, и можно выбрать
«Установить», «Починить», «Обновить мод» или «Удалить». Стрелки и Enter, Esc — выход.

То же самое без меню:

```powershell
ymdmod install     # поставить мод или обновить его до последней версии
ymdmod repair      # встроить мод заново, например после обновления Яндекс Музыки
ymdmod uninstall   # вернуть клиент в исходное состояние
ymdmod status      # посмотреть, что сейчас стоит
```

Если клиент открыт, `ymdmod` сам его закроет и потом запустит снова.

### Обновления

**Яндекс Музыки.** Яндекс при обновлении ставит клиент заново, и мод из него пропадает. Ничего не ломается,
клиент просто снова обычный. Выполните `ymdmod` и выберите «Починить» — всё вернётся вместе с вашими аддонами
и настройками.

**Мода.** Мод сам проверяет, не вышла ли новая версия, и пишет об этом в клиенте. Кнопка «Обновить» закроет
клиент, обновит мод и откроет клиент снова. Если уведомление уже закрыли — та же кнопка есть наверху вкладки
«Каталог», а ещё можно выполнить `ymdmod install`. Архив новой версии сверяется с контрольной суммой из
релиза на GitHub; если что-то не сошлось, мод останется прежним.

### Удаление

`ymdmod` → «Удалить». Клиент вернётся в исходное состояние, потом мод спросит, удалить ли его файлы и команду
`ymdmod`. Настройки мода остаются в `%APPDATA%\YandexMusic\YMDMod` — их можно удалить руками.

### Что стоит знать

- Чтобы встроить мод, приходится менять файлы клиента (`app.asar` и `Яндекс Музыка.exe`), поэтому цифровая
  подпись exe перестаёт сходиться. После удаления мода возвращаются оригинальные файлы, и подпись снова
  в порядке.
- Мод не трогает ваш аккаунт, подписку и загрузку треков и не обходит никакую защиту.
- Аддоны — это код, который работает внутри клиента. В каталоге только проверенные аддоны; ставить что-то
  «из папки» стоит, только если доверяете автору.

<details>
<summary><b>Если что-то пошло не так</b></summary>

<br>

Сначала попробуйте `ymdmod` → «Починить». Если не помогло, пригодятся:

- лог мода: `%APPDATA%\YandexMusic\YMDMod\ymdmod.log`;
- что мод нашёл в клиенте: `%APPDATA%\YandexMusic\YMDMod\support.json`;
- лог загрузчика, если мод вообще не стартует: `%TEMP%\ymdmod-loader.log`;
- вывод `ymdmod status`.

С ними можно открывать [issue](https://github.com/YMDMod/YMDMod/issues) — так разобраться в проблеме гораздо
быстрее.

</details>

```powershell
npm test
```

Релиз — тег `vX.Y.Z`, совпадающий с версией в `package.json`. Архив `ymdmod-X.Y.Z.zip` с контрольной суммой
GitHub Actions соберёт и приложит к релизу сам.
